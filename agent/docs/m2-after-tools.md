# M2 측정: 도구 결과를 받은 뒤 모델이 무엇을 하는가

- 측정: 2026-10-18 10:07, `scripts/measure_after_tools.py`. 정답 도구 호출 하나를 가짜 백엔드로 실행해 그 결과를 넣었다.
- 문제: 결과가 있는(ok) 85개 + 빈 결과·준비 중·미지원 20개 (v2 test·human_style에서 정답이 도구 하나인 것)
- A = 그대로(학습 때 system + 도구 8개, 일반 에이전트 루프) / B = 답변 전용 system(6.4절) + 도구 없음 + `<tool_call>` 토큰 막음
- v3 = 파인튜닝 모델(LoRA), base = 파인튜닝 전 기본 모델. temperature 0

## 예시

- **v3 A · 제한을 알림** (search_destinations) “다음 달에 청송 가는데 반려견과 갈 수 있는 펜션 골라줘” → 지역별 여행지 검색 기능은 아직 준비 중이어서 반려견과 갈 수 있는 펜션을 찾아드릴 수 없습니다. 잠시 후 다시 도와드릴게요.
- **v3 A · 결과를 근거로 답함** (recommend_by_keywords) “박물관 하나만 골라줘” → 국립중앙박물관은 서울특별시 용산구에 위치한 인문관광 > 문화시설 > 박물관으로, 서울의 대표적인 박물관 중 하나예요.
- **v3 A · 학습한 정형 문장** (recommend_similar_traveler_routes) “남자이고 22살, 엠비티아이는 INFP야. 나 같은 사람들 여행 루트 궁금해” → 비슷한 여행자를 찾으려면 나이, 성별, MBTI가 필요해요. 알려주시겠어요?
- **v3 A · 도구를 또 부름(같은 도구)** (get_weather) “합천 오늘 우산 챙겨야 할까?” → (빈 답)
- **v3 A · 도구를 또 부름(다른 도구)** (recommend_by_keywords) “축제 좀 알려줄래?” → (빈 답)
- **v3 A · 결과 이름을 하나도 안 씀** (recommend_by_keywords) “레크리에이션이랑 온천이랑 전망대 좋아하는 사람한테 딱인 여행지 있을까?” → 어떤 여행지를 좋아하시는지 알려주시면 더 정확히 찾아드릴 수 있어요.
- **v3 A · 결과에 없는 숫자** (search_reviews) “삿포로 시계탑 다녀온 분들 평가 좀 알려 주세요” → 삿포로 시계탑을 다녀온 여행자는 다음과 같이 후기를 남겼습니다:

- **후기 제목**: "삿포로 시계탑 생각보다 작았지만 좋았어요"
- **좋아요 수**: 8개
- **작성일**: 2024년 2월 11일

후기 내용은 "작았지만 좋았어요"라고 표현하며, 전체적인 느낌은 긍정적인 것으로
- **v3 B · 제한을 알림** (search_destinations) “다음 달에 청송 가는데 반려견과 갈 수 있는 펜션 골라줘” → 지역별 여행지 검색은 아직 준비 중이에요.
- **v3 B · 결과를 근거로 답함** (recommend_by_keywords) “박물관 하나만 골라줘” → 국립중앙박물관, 서울특별시 용산구
- **v3 B · 결과 이름을 하나도 안 씀** (search_reviews) “도동항 다녀온 분들 평가 좀 알려 주세요” → 울릉도 도동항에서 첫 배를 타고 간 후기를 5개가 있습니다.
- **base A · 제한을 안 알림(지어냈을 수 있음)** (search_destinations) “다음 달에 청송 가는데 반려견과 갈 수 있는 펜션 골라줘” → 청송 지역의 반려견과 함께 갈 수 있는 펜션 정보는 현재 제공되지 않습니다. 청송 지역의 숙박 정보를 더 자세히 검색할 수 있도록, 추가로 조건을 알려주시면 도움드리겠습니다. 예를 들어, 펜션의 가격대, 위치(예: 산간, 도시 근처), 또는 특별한 요구사항(예: 수영장 있음)도 알려주시
- **base A · 결과를 근거로 답함** (recommend_by_keywords) “박물관 하나만 골라줘” → 추천하는 박물관: **국립중앙박물관**  
- 위치: 서울특별시 용산구  
- 분류: 인문관광 > 문화시설 > 박물관  

이 박물관은 서울의 대표적인 문화 공간 중 하나로, 다양한 전시와 역사적 자료를 통해 지역과 국가의 문화를 깊이 있게 경험할 수 있습니다.
